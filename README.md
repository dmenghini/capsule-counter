# Capsule Counter

A computer vision-based system for automatically detecting and counting elliptical capsules using Python and OpenCV.

## Project status

Proof of concept / under development.

## Objective

Develop a system that:
- Detects individual capsules on a flat surface.
- Counts the total number of capsules.
- Detects additions and removals continuously.
- Provides a visual representation of detected objects.

## Technology

- Python
- OpenCV
- NumPy

## Development roadmap

1. Static image detection proof of concept.
2. Detection accuracy evaluation and improvement.
3. Live camera integration.
4. Continuous counting.
5. Desktop user interface.
